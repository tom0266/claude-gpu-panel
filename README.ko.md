# gpu-panel

GPU 서버를 여럿이 나눠 쓰는 사람을 위한 Claude Code 패널.

프롬프트 밑 한 줄에 어느 GPU 가 돌고 있는지, 내 학습이 몇 개 떠 있는지, 플랜
한도가 얼마나 남았는지가 나온다. `gpu` 를 누르면 옆 창이 열려 카드 전체와
누가 쓰고 있는지, 내 job 의 경과 시간까지 보여 준다.

[English](README.md)

```
  ⚠ auto mode on (shift+tab to cycle)

  ┌───────────────────────────────────────────────────────────────────────┐
  │ my session  5h ━━ 4% 4h20m  7d ━ 29% 4d0h  ctx 18%  gpu 2:15%  job 2  │
  │ effort low [medium] high xhigh │ model [fable 5.2] opus 5.5 │ ⟲ compact│
  └───────────────────────────────────────────────────────────────────────┘
```

이런 패널은 대개 프롬프트 위에 붙고 플랜 사용량을 보여 준다. 이것은 프롬프트
아래 힌트 줄 옆에 자리를 잡고, 먼저 보는 것이 남들과 같이 쓰는 그 기계다.

## 보여 주는 것

**프롬프트 밑 줄**

| 칸 | 뜻 |
|---|---|
| 세션 이름 | `/rename` 으로 붙인 이름, 없으면 자동 제목 |
| `5h` `7d` | 플랜 사용량 막대와 초기화까지 남은 시간 |
| `ctx` | 컨텍스트 창이 얼마나 찼는지 |
| `gpu` | 돌고 있는 카드만 `번호:사용률` 또는 `번호:메모리`, 없으면 `free` |
| `job` | 감시 대상 학습이 몇 개 떠 있는지. 0 이면 숨김 |
| `agents` | 돌고 있는 서브에이전트를 모델별로, 끝난 것과 실패한 것 |
| 버튼 | effort 전환, 모델 전환, `/compact` 실행 |

모델 버튼의 버전은 실제로 써 본 모델에서 배운다. `opus` 를 한 번 쓰고 나면
`opus 5.5` 가 되고, 그 값은 세션이 바뀌어도 남는다. 하드코딩이 없으니 낡지
않는다.

폭이 110 칸 미만이면 테두리와 막대, 라벨을 빼고 두 줄에 맞춘다. 화면을 셋으로
나눈 pane 에서도 쓸 수 있다.

**`gpu` 창** — `gpu` 칸을 누르거나 `/gpu`

```
  GPU
  0 ━━━━━━━━     0%   0/45G 31°C
    free
  2 ━            15%   1/48G 54°C
    you 1G, alice 22G

  Jobs
  2733273  4-02:11:08  python train.py --fold 3
```

카드마다 사용률·메모리·온도와 **쓰고 있는 계정**이 나온다. 내가 쓰려는 카드가
비었는지, 남의 학습이 올라가 있는지 한눈에 보라는 것이다. 그 밑에는 내
감시 대상 job 이 PID 와 경과 시간과 함께 나온다. 창이 열려 있는 동안 10초마다
갱신하고, 닫혀 있으면 조회를 아예 돌리지 않는다.

## 설치

Claude Code 2.1.287 이상이 필요하다.

```bash
claude plugin marketplace add tom0266/claude-gpu-panel
claude plugin install gpu-panel@claude-gpu-panel
```

그다음 열린 세션에서 `/reload-plugins`, 또는 새 세션을 연다.

GPU 와 job 칸은 기계가 값을 낼 수 있을 때만 나온다.

- **GPU** 는 `PATH` 에 `nvidia-smi` 가 있어야 한다. 없으면 칸이 숨겨지니
  노트북에서도 나머지는 그대로 쓴다.
- **job** 은 `~/.claude/statusline-jobs.txt` 가 있어야 한다. 한 줄에 패턴
  하나를 적고, 그 문자열이 프로세스 명령줄 어디에든 들어 있으면 센다. 빈 줄과
  `#` 로 시작하는 줄은 건너뛴다.

  ```
  # ~/.claude/statusline-jobs.txt
  train.py
  finetune
  optuna
  ```

  내 계정 프로세스만 세고, 같은 명령줄은 한 번만 센다.

## 명령

| | |
|---|---|
| `/gpu` | GPU·job 창을 연다 |

나머지는 전부 클릭이다.

## 비용

플랜 사용량과 컨텍스트는 Claude Code 가 이미 올리는 이벤트에서 읽으니 공짜다.
타이머로 10초마다 `nvidia-smi` 와 `ps` 를 돌리고, 30초마다 세션 기록에서
제목을 찾는다. 네트워크 요청은 없고 모델도 부르지 않는다.

## 설정

색은 `hooks/register.tsx` 위쪽의 상수 `C` 하나에 모여 있다. 각 값은 hex 색이나
테마 키다. 거기서 고치고 다시 설치하면 된다.

한도 알림 임계치는 같은 파일의 `THRESHOLD` 다. 5시간 창은 80%, 7일 창은 70%
이고, 창마다 초기화될 때까지 한 번만 알린다.

## 한계

- 터미널과 데스크톱 앱의 Code 탭에 그려진다. `claude -p` 와 클라우드 세션은
  hook 은 돌지만 아무것도 그리지 않는다.
- GPU 창이 보여 주는 것은 계정이지 사람이 아니다. 다들 한 계정을 같이 쓰는
  기계에서는 알려 주는 것이 적다.
- effort 는 `/effort` 입력과 패널 버튼을 지켜보며 따라간다. Claude Code 가
  현재 값을 알려 주지 않아서, 다른 경로로 바뀌면 다음 변경 때까지 강조가
  어긋날 수 있다.
